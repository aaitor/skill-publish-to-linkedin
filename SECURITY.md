# Security policy

Report vulnerabilities privately to **aaitor@gmail.com**. Include the affected commit/version, impact, and a minimal reproduction with synthetic data. Do not include access tokens, app secrets, personal posts, or live account data. Use private reporting in the Security tab if available.

Do not open public issues for vulnerabilities or test exploit behavior against another account. Security fixes target the latest default branch unless a release-specific policy is documented. This is a community-maintained tool with no guaranteed response or remediation time.

See [security and privacy](docs/security-and-privacy.md) for credential storage and revocation. Token expiry and ordinary authorization failures belong in [troubleshooting](docs/troubleshooting.md).
